- 誕生日・総合馬術・性格タグ・特徴タグを登録

- 既存の馬プロフィール、交流、DM、グッズ等の画面は維持

GitHubへの反映方法
1. ZIPを展開する
2. index.html をリポジトリ直下の index.html に上書きアップロード
3. ZIP内の media フォルダにあるファイルを、リポジトリ直下の既存 media フォルダに追加アップロード
   ※既存 media フォルダは削除・置換せず、新しいファイルだけ追加してください
4. GitHubの main にコミットすると、Vercelが自動デプロイします

注意
- 写真・動画は提供いただいた素材をブラウザ表示向けに最適化しています。
- 動画のうちMOV形式の2本はMP4に変換しています。
- 毛色はソラリス・ドラドについて写真からの暫定設定です。必要なら後で修正できます。
- サポーター数・支援額は未設定のため0で登録しています。
- 投稿・コミュニティ等の操作はデモ状態で、共有DBには保存されません。
