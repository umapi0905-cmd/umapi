うまぴ 改修版

今回の変更
- 下部ナビゲーションから「グッズ」「予定」を一時的に外しました。
- ホーム上部の馬アイコンをタップすると、該当する馬の投稿をストーリー風に表示します。左右のタップ領域で前後の投稿へ移動できます。
- 下部ナビゲーションに「リール」を追加しました。登録済み動画を縦スクロール・スナップで連続再生する画面です。
- 競走馬・引退馬プロフィールに競走馬データ欄を追加しました。現段階では馬名・生年の照合前に誤った血統や賞金を掲載しないため、netkeiba確認への導線と注意書きを表示します。

重要
- index.html だけでなく、既存の media/ フォルダもGitHubリポジトリに残してください。HTML内で media/dorado_video1.mp4、media/dorado_video2.mp4、media/meisa_video.mp4 などを参照しています。
- 動画ファイルが media/ に存在しない場合、リール画面に動画は表示されません。その場合は動画ファイルを送ってください。
- 現在はデモアプリです。ログイン、個人情報の保存、決済、投稿のサーバー保存は未実装です。
- 競走成績・血統・獲得賞金はnetkeiba等で馬名と生年を照合していないため、実データとしては未掲載です。
