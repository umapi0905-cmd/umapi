# うまぴ デモアプリ（コミュニティ・DM・グッズ追加版）

## 内容
- `index.html`：うまぴのデモアプリ本体
- `media/carrot-thank-you.mp4`：人参を食べるお礼動画（DMデモで再生）
- `vercel.json`：Vercel向け設定

## 今回の変更
- 推し馬を探す画面・ファンコミュニティ画面の書体を初期デモアプリの共通フォントに統一
- Xのコミュニティを参考に、馬ごとのファンコミュニティ、参加ボタン、タイムライン、いいね、コメントを追加
- 推し馬の公式アカウントから「送ってくれた人参を食べたよ」という動画付きDMが届くデモ画面を追加
- ポスター、クリアファイル、ぬいぐるみ等を並べたグッズ販売ページを追加

## ローカルで確認
`index.html` をブラウザで開いてください。動画ファイルは相対パス `media/carrot-thank-you.mp4` から読み込みます。

## デモ上の注意
- コミュニティの投稿・いいね・コメント、DM、グッズ購入は画面デモです。実際の複数ユーザー間同期、DM送受信、決済は接続していません。
- 動画は添付いただいた素材をWebブラウザで再生しやすいMP4（H.264）に変換しています。
- グッズ名・価格はデモ用サンプルです。実際の販売には商品登録、在庫、決済、配送機能が必要です。
- Vercelへ反映する場合は、`index.html`、`vercel.json` と `media` フォルダを同じ階層でGitHubリポジトリの `main` にアップロードしてください。
